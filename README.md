# 소리지도

방송 대사에서 등록된 장소를 찾고, 장소 ID를 고주파 오디오 신호로 전송하는 모바일 웹 도구입니다. 청취자가 휴대폰에서 수신을 시작하면 받은 장소와 카카오맵 링크가 화면에 표시됩니다. 기본 목록에는 덕진공원 등 전주 명소 9곳이 들어 있습니다.

## PC에서 실행

Node.js가 설치된 PC에서 저장소를 열고 실행합니다. 별도 패키지 설치 없이 사용할 수 있습니다.

```powershell
npm.cmd start
```

브라우저에서 [청취자 수신](http://127.0.0.1:4173/)을 열고 **덕진공원 데모**를 누르면 문장에서 장소 검색, 신호 인코딩과 디코딩, 장소 표시를 마이크 없이 확인할 수 있습니다. 방송 진행자는 [방송 스튜디오](http://127.0.0.1:4173/?mode=studio)를 엽니다.

## 휴대폰에서 실제 수신

1. 이 저장소의 `index.html`, `styles.css`, `app.js`, `audio-input.js`, `audio-modem.js`, `places.js`를 같은 디렉터리에 두고 HTTPS로 제공합니다. 정적 웹 호스팅을 쓰거나, 아래 명령으로 휴대폰이 신뢰하는 인증서를 지정해 같은 네트워크에서 테스트할 수 있습니다.
2. 휴대폰 브라우저에서 HTTPS 주소를 열고 **수신 시작**을 눌러 마이크 권한을 허용합니다. 페이지를 화면에 띄운 상태에서 스피커에 가까이 둡니다.
3. PC의 **방송 스튜디오**에서 **지금 보내기**를 누릅니다. 정상 수신하면 휴대폰에 덕진공원이 표시됩니다. **카카오맵에서 보기**를 눌러 지도로 이동합니다.

휴대폰에서 접속할 수 있는 이름 또는 IP가 인증서에 포함되어야 합니다. 같은 네트워크의 PC 주소에 일반 HTTP로 접속하는 경우 브라우저 마이크를 사용할 수 없습니다. [W3C Media Capture and Streams](https://www.w3.org/TR/mediacapture-streams/#dom-mediadevices-getusermedia)

```powershell
$env:HOST = "0.0.0.0"
$env:TLS_CERT = "C:\path\to\certificate.pem"
$env:TLS_KEY = "C:\path\to\private-key.pem"
npm.cmd start
```

## 방송에 연결

- **실시간** — 방송 PC에서 브라우저 오디오 출력을 믹서의 별도 입력에 연결합니다. **자동 음성 인식 시작**을 누른 뒤 방송 마이크에 “오늘은 덕진공원에 가볼까요?”라고 말합니다. 한국어 인식이 확정되면 약 1초 동안 결과를 모아 장소를 선택하고 신호를 재생합니다. 브라우저가 마이크 오디오를 자체 음성 인식 서비스로 보낼 수 있습니다. 음성 인식 서비스 없이도 **대사에서 찾아 보내기**와 **지금 보내기**를 사용할 수 있습니다. [Web Speech API](https://webaudio.github.io/web-speech-api/#introduction)
- **녹음** — 장소를 선택해 **WAV 다운로드**를 누르고, 파일을 대사의 장소 언급 직후 별도 오디오 트랙으로 믹싱합니다. 앱은 48 kHz, 16비트 모노 PCM WAV를 생성합니다.
- **송출 대역** — 신호 주파수는 20.3·21.1 kHz입니다. 일반 FM 오디오의 15 kHz 대역에서는 신호가 제거되며, 디지털 방송이나 스트리밍에서도 코덱, 필터, 스피커, 휴대폰 마이크가 이 주파수를 보존해야 동작합니다. 테스트할 때는 낮은 볼륨에서 시작해 송출 이후의 실제 재생 장치로 수신을 확인합니다. [FM 스테레오 규격](https://www.govinfo.gov/content/pkg/CFR-2025-title47-vol4/pdf/CFR-2025-title47-vol4-sec73-322.pdf)

## 장소 표시 기준

한 발화에서 등록 장소 한 곳을 찾으면 보내고, 여러 곳을 나열하면 소개 대상이 분명할 때만 한 곳을 선택합니다. 송신과 수신 모두 가장 최근 장소 이후 최소 15초, 같은 장소는 최소 45초 간격을 적용합니다. 수신 오디오는 휴대폰 브라우저에서 처리합니다.

장소를 추가하려면 `places.js`의 목록에 새 항목을 추가하고, 송신과 수신 화면에 동일한 버전을 배포합니다. 기존 ID는 이전 신호와의 호환을 위해 유지합니다.
